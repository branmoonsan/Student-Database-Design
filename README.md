# Student-Database-Design
Designed and built a centralized relational student management database in Google Sheets by integrating six years of Google Forms registration data. The database supports student information, program enrollments, and digital portfolio management for more than 1,500+ students.

<img width="900" alt="image" src="https://github.com/branmoonsan/Student-Database-Design/blob/main/img/Student_Database_ERD.png">

***

## Project Overview

During my time at [A Team Academy](https://ateamacademy.org/), student registrations were collected through multiple Google Forms across different training programs over six years. Student information became scattered across numerous spreadsheets.
To solve this problem, I designed and built a relational database in Excel by consolidating all historical registration data into a centralized database.
